# Alunos Angular

Angular app for managing students with Backendless.

## Features

- List students
- Add new students
- Real-time updates with Backendless

## Tech Stack

- Angular 19 (standalone components)
- Backendless SDK
- TypeScript

## Development

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Migrated

- Upgraded from Angular 8 to Angular 19
- Migrated from module-based to standalone components
- Updated to use signals instead of BehaviorSubject
